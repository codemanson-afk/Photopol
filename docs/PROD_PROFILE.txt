Photopol — Production profile

Set in production .env (or Compose):

  ENVIRONMENT=production
  DEBUG=false
  SECRET_KEY=<long random>
  CORS_ORIGINS=https://photopol.us
  JOB_EXECUTION_MODE=queue
  USE_SIGNED_URLS=true
  GUEST_LIMITS_ENABLED=true
  REPLICATE_API_TOKEN=...
  STRIPE_ENABLED=true
  STRIPE_SECRET_KEY=...
  STRIPE_WEBHOOK_SECRET=...
  STRIPE_PRICE_ID_CREDITS=...
  STRIPE_PRICE_ID_PRO_MONTHLY=...
  STRIPE_PRICE_ID_BUSINESS_MONTHLY=...
  # Optional second provider:
  # PADDLE_ENABLED=true
  # PADDLE_API_KEY=...
  # PADDLE_WEBHOOK_SECRET=...
  # PADDLE_PRICE_ID_CREDITS=...
  # PADDLE_PRICE_ID_PRO_MONTHLY=...
  # PADDLE_PRICE_ID_BUSINESS_MONTHLY=...
  FAL_KEY=...   # optional upscale failover

Run worker:

  arq app.worker.WorkerSettings

  # or: docker compose up worker

Horizontal scale: increase worker replicas behind the same REDIS_URL.
