Photopol — What We Have So Far
Updated: 2026-08-23
Product: Photopol (photopol.us) — AI image editing SaaS
Domain target: photopol.us

================================================================================
1. STACK
================================================================================

Frontend:  Next.js 15, TypeScript, Tailwind CSS
Backend:   FastAPI, SQLAlchemy, Alembic, Pydantic
Database:  PostgreSQL
Cache:     Redis (used for Arq job queue when JOB_EXECUTION_MODE=queue)
Storage:   S3-compatible (MinIO locally)
AI:        Replicate + local rembg + remove.bg (configurable)
Payments:  Stripe + Paddle (env on/off; packs + subscriptions + portals)
Deploy:    Docker Compose (postgres, redis, minio, backend, worker, frontend)

5. BACKEND CAPABILITIES
================================================================================

Auth
  Register / login / logout, JWT Bearer, USER + ADMIN roles
  Guest sessions with optional caps (GUEST_LIMITS_ENABLED)

Projects & media
  Create projects, upload images (JPEG/PNG/WEBP), ownership checks
  Immutable originals + ImageVersion history
  Replace-in-place upload path for workspace

Jobs (Phase 2)
  POST /api/jobs          Create + enqueue (or inline in dev)
  GET  /api/jobs/{id}     Poll status / progress / result
  Credit hold on enqueue → deduct on success → release on fail
  Idempotency keys
  Worker: arq app.worker.WorkerSettings (Compose service: worker)

Billing
  Stripe + Paddle (STRIPE_ENABLED / PADDLE_ENABLED)
  Credit packs (Checkout mode=payment)
  Subscriptions Pro / Business (mode=subscription)
  Customer portals (provider-aware)
  Stripe webhooks: /api/billing/webhook[+ /stripe]
  Paddle webhooks: /api/billing/webhook/paddle
  Plans: free / pro / business (monthly credit allowances)

Credits
  Ledger with idempotent transactions
  reserved_credits on users
  Configurable costs via env

Admin
  Ops console: Overview, Users (patch plan/role/active), Jobs, Projects,
  Credits ledger, Billing snapshot (read-only), Audit log
  API under /api/admin/* · admin_audit_logs

AI providers
  Background: local rembg | remove.bg | Replicate (AI_BG_PROVIDER)
  Object remove / upscale / enhance: Replicate with local fallbacks
  Tool registry: backend/app/services/tool_registry.py
