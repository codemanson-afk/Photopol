Photopol — Product Direction
Updated: 2026-08-24

================================================================================
PHILOSOPHY (LOCKED)
================================================================================

Users tell Photopol WHAT RESULT they want. AI hides the complexity.

NOT: Photoshop with 50 buttons (layers, masks, brushes, tool names)
NOT: A website of separate AI tools (Remove BG, Upscale, Crop…)
NOT: Upload → tool → download → re-upload → another tool

YES: Upload → AI understands → simple outcome choices → AI does the work → Done

User mental model:
  “I want to edit my image.”
  → Edit Image → upload → AI recommends / user picks a result
  → Photopol runs the hard part automatically → professional result

Internal jobs (remove_bg, enhance, upscale, crop…) are IMPLEMENTATION DETAIL.
They must not appear as products or primary UI labels.

================================================================================
PRIMARY PRODUCTS (HUB) — sell RESULTS
================================================================================

1. Edit Image — one AI image workspace
   Upload → analyze → outcome cards (e.g. “Online store ready”,
   “Look professional”, “Instagram ad”, “Describe what you want”)
   → one Run → before/after → export.
   Advanced / fine-tune (manual capabilities) is optional and hidden —
   never the default path.

2. Create with AI
   Describe what you want. AI decides image / multi-image / design path.
   (Hub stub → full later)

3. Create Video
   Describe + duration + platform + style. AI handles production.
   (Hub stub → full later)

4. AI Captions
   Upload video → speech → beautiful captions. User picks language/style only.
   (Hub stub → full later)

“AI Auto Edit” is folded INTO Edit Image (same experience), not a separate tool mall.

Edit Image UI (Intelligence workspace):
  Sidebar products · before/after slider · NL + outcome chips ·
  “Your image is ready” checklist · on-demand variations · Download CTAs.
  Manual fine-tune is hidden behind More Options.

================================================================================
OUTCOME EXAMPLES (Edit Image)
================================================================================

“Make this ready for my online store.”
  → enhance + remove background (cutout)

“Make this look professional.”
  → enhance + remove background

“Make this an Instagram advertisement.”
  → enhance + remove background

Custom: user types the result in plain language → Replicate Flux Kontext edits THIS photo
  (real instruction-following AI, not keyword recipes).

Presets (store / professional / IG chips): enhance + remove background.

Show humans WHAT will improve (Lighting · Sharper · Clean backdrop / Applied your request) —
never model or tool SKUs.

================================================================================

================================================================================

Ledger still records real jobs underneath.

Users buy Photopol credits — never buy a tool.
